# Pratham — Developer Landing

A standalone 3D developer landing page, separate from the full portfolio. Black and amber art direction, interactive orbital graphics, and paths into work, code, and writing.

## Deployment

GitHub Pages serves the root of the main branch. No build step or API keys are required.

## Development

Serve this folder with a local static server. Edit index.html, style.css, and app.js. Three.js is vendored under its MIT license (THREE-LICENSE.txt).

## Accessibility

Keyboard rotation, pause and reset controls, reduced-motion support, and a CSS fallback when WebGL is unavailable.
