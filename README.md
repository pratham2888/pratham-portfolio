# Pratham Portfolio

The complete, standalone portfolio for Pratham Bhanushali: engineering, product, data, research, and From Pilot to Prod.

**Website:** https://pratham2888.github.io/pratham-portfolio/

## Run
Serve the repository root with any static HTTP server. There is no build step, server, API key, or dependency installation. GitHub Pages publishes the root of main.

## Contents
- index.html: complete portfolio, project evidence, public repositories, approach, writing, background, and contact.
- style.css: responsive black-and-amber design, subtle reveals, and motion preferences.
- app.js: route selector, email copy, and interactive orbital sculpture.
- three.module.js / three.core.js: locally hosted Three.js, MIT licensed in THREE-LICENSE.txt.

## Accessibility and resilience
Keyboard rotation, pause, reset, reduced-motion preferences, native expandable case studies, and an HTML/CSS graphic fallback. Google Fonts is optional; system fonts remain usable. All portfolio content and core links are available without JavaScript.
